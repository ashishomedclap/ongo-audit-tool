## 5. Emergency 4-Step Malware Cleanup Protocol

### Step 1: Database Purge (MySQL / phpMyAdmin)
Run the following SQL commands to permanently delete injected posts and orphaned metadata:
```sql
-- 1. Identify and delete spam casino posts
DELETE FROM wp_posts 
WHERE post_name REGEXP '(casino|pokies|bingo|slots|blackjack|spins|bonus|plinko|bet365)'
   OR post_title REGEXP '(casino|pokies|bingo|slots|blackjack|spins|bonus|plinko|bet365)';

-- 2. Remove orphaned post metadata
DELETE pm FROM wp_postmeta pm 
LEFT JOIN wp_posts wp ON wp.ID = pm.post_id 
WHERE wp.ID IS NULL;

-- 3. Remove orphaned term relationships
DELETE tr FROM wp_term_relationships tr 
LEFT JOIN wp_posts wp ON wp.ID = tr.object_id 
WHERE wp.ID IS NULL;
```

### Step 2: Server-Level HTTP 410 Gone Rules
Add this rewrite block to the very top of `.htaccess` (Apache) or `nginx.conf` so Googlebot receives `410 Gone` and accelerates de-indexing:

**For Apache (`.htaccess`):**
```apache
<IfModule mod_rewrite.c>
RewriteEngine On
RewriteRule ^.*(casino|pokies|bingo|slots|blackjack|free-spins|no-deposit|jili).*$ - [G,L]
</IfModule>
```

**For Nginx:**
```nginx
location ~* /(casino|pokies|bingo|slots|blackjack|free-spins|no-deposit|jili) {
    return 410;
}
```

### Step 3: Security Hardening & Credential Rotation
* Rotate all WordPress admin passwords, database passwords (`wp-config.php`), and FTP/SSH keys.
* Re-install core WordPress files (`wp-admin`, `wp-includes`) from official repository.
* Run a full Wordfence or Sucuri server-level file integrity scan.
