## 🎨 Design System & UI/UX Features

- **880px Glassneumorphic Mega-Menu**: Expansive dual-column responsive dropdown symmetrically centered directly beneath the primary pill navigation bar, featuring direct 1-click book volume jumpers.
- **Glassneumorphism & Bento Grid**: Modern frosted-glass surfaces (`backdrop-filter: blur(28px) saturate(180%)`), dual-layer bevel highlights, subtle glowing borders, and asymmetric card hierarchies.
- **Live Federal API Integrations**: Zero-subscription integrations with the US CMS NPPES Doctor Registry and Google PageSpeed Insights.
- **Dark Mode Contrast Engine**: High-contrast, radiant emerald, sky, and obsidian tokens ensuring 100% text readability with automatic OS theme synchronization and manual toggle.
- **Multi-Pass Instant Scroll-To-Top**: Eliminates tab transition disorientation by resetting scroll coordinates across `window`, `document`, and main content mounts.

## 🚀 Quickstart

```bash
# Navigate to the Next.js app
cd audit-tool

# Install packages
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. Press `⌘K` / `Ctrl+K` to open the Command Palette from any page.
